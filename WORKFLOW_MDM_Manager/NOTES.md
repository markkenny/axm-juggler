# DESCRIPTION

Takes a serial, or CSV of serials to change MDM assignment in bulk. 

It's paramterised options for debug, silent, confirm to pass serials to following policies, or run in Self Service for limited ABM MDM changes.

Lots of time spent optimising for speed without hitting Apple API rate limits.

Needs the local Git repo for all the token management scripts.
